# Pacote atual: 2.8.1

A versão atual padroniza os painéis dos menus para vidro cinza. Compilação integral e 29 testes aprovados, incluindo preservação de componentes/callbacks dos botões e das cores de itens negociados.

O workflow manual **Upload tested release JAR** confere `SHA256SUMS` e publica o JAR da versão em `gradle.properties`. Para compilar: `./gradlew build`. Os pacotes anteriores permanecem como referência histórica.
